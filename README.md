A 60-minute, read-only investigation and advisory lab for Security Cloud Solution Architects. Use representative Microsoft Defender XDR evidence to build an architecture map, a prioritized adoption roadmap, and a customer value narrative.

## Access and preparation

- Your facilitator supplies access to an authorized demo tenant. This repository does not provide tenant access, credentials, or licenses.
- Replace `YOUR-TENANT-ID` in the instructions and portal URLs with the tenant ID supplied by your facilitator.
- The incident and attack-path examples depend on the original demo dataset. Facilitators must confirm that Incident 74802 and the specified attack path are available, or adapt those examples before delivery.
- Demo-tenant evidence is representative, not data about the fictional customer Caldova.
- Keep the lab read-only. Do not change incident assignments, classifications, policies, or other tenant settings.
